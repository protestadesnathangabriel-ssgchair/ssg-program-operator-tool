SSG PROGRAM OPERATOR TOOL — PROMPTER PERFORMANCE FIX

This update targets:
- Lag/buffering when using keyboard controls and auto-scroll in Program Flow and Program Sequence.
- Lyric Prompter scroll stutter/jumps after a brief pause.

Code changes in index.html:
- Program Flow/Sequence auto-scroll uses elapsed time instead of a fixed increment per animation frame, so speed is less dependent on display refresh rate.
- The control-preview mirror sends large prompt/timer HTML only when that content changes, rather than repeatedly sending it with every scroll update.
- Lyric display avoids rebuilding identical lyric markup on every incoming state message.
- Lyric auto-scroll clamps unusually long animation-frame gaps to reduce sudden jumps after scheduling delays.

ADDITIONAL PROGRAM FLOW / PROGRAM SEQUENCE FIX
- Live guide updates now re-render the display while preserving its current scroll position without restarting the active item's smooth-scroll animation on every incoming edit.
